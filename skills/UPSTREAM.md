# Upstream

`appllama-usage` and `appllama-app-design-skill` are MIT copies of
[Appllama/appllama-skills](https://github.com/Appllama/appllama-skills).

Refresh:

```bash
npx skills@latest add appllama/appllama-skills -g -a grok -a claude-code -y --copy
rsync -a --delete ~/.grok/skills/appllama-usage/ skills/appllama-usage/
rsync -a --delete ~/.grok/skills/appllama-app-design-skill/ skills/appllama-app-design-skill/
```
