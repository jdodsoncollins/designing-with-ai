# Seed-string variety loop

The model cannot act randomly. Run this 3–4 times. Present the variants. Do not deepen the first one.

```
Build [product] for [job].

Follow this procedure:

1. Generate a long random alphanumeric string using a shell script
   (`openssl rand -hex 32`).
2. Define the creative direction (color, layout, typography, motif)
   from subpatterns in that string. Look past the surface.
3. Use your judgment to make that direction look great.

Do not reveal the string in the design. It is only for inspiration.
Do not add a second variant in this run.
```

After 3–4 independent runs, pick one with the user. Then switch to the critic loop.

Ambitious-brief alternative (when the user already has a dangerous inspiration): skip the string, name the inspiration in the prompt, still generate 3–4 takes.
