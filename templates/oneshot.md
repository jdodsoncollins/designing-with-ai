# Named-product one-shot

Fill the brackets. Attach 4–8 screenshots. Do not add “make it beautiful.”

```
Use [reference library or MCP if present].

Build [product name]: [one-sentence job].

It should have the flows of [App A]
and the design of [App B].
```

Example (Jaimin / Appllama, 2026-09-07):

```
Use appllama mcp & skills, build an astrology app Stelari,
it should have the flows of Chani and design it like Blank Spaces.
```

App A and App B should be different products. Flow and look are separate borrowings.

If no MCP is connected, the screenshot packet *is* the library. Attach it.
